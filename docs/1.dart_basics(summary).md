# Dart 기본 문법: 변수와 메소드 (`main.dart` 기준)

이 문서는 Flutter 앱의 핵심 파일인 `main.dart`를 기준으로 Dart 언어의 가장 기본적인 문법인 변수와 메소드에 대해 설명합니다.

---

### `main.dart` 파일 분석: Flutter 앱의 시작점

`main.dart` 파일은 Flutter 앱이 시작될 때 가장 먼저 실행되는 코드를 담고 있습니다.

#### 1. `import` 문: 필요한 도구 가져오기

다른 파일에 있는 코드(클래스, 함수 등)를 현재 파일에서 사용하고 싶을 때 `import`를 사용합니다.

```dart
// lib/main.dart

import 'dart:async'; // 비동기 프로그래밍 도구
import 'package:flutter/material.dart'; // 머티리얼 디자인 UI 위젯
import 'package:pedometer/pedometer.dart'; // 걸음 수 감지 외부 라이브러리
import 'package:myapp/tabs/step_tab_page.dart'; // 직접 만든 다른 화면 파일
```

#### 2. `main()` 함수: 앱의 시작

모든 Dart 프로그램은 `main()` 함수에서 시작됩니다. `runApp()` 함수는 Flutter 앱을 실행하고 화면에 첫 위젯을 표시합니다.

```dart
// lib/main.dart

void main() {
  runApp(const MyApp());
}
```

#### 3. `MyApp` 클래스: 앱의 최상위 루트 위젯

`MyApp` 클래스는 앱 전체의 시작점이자 최상위(루트) 위젯입니다. 앱의 기본 설정과 구조를 정의합니다.

```dart
// lib/main.dart

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Pedometer App',
      theme: ThemeData(...),
      darkTheme: ThemeData(...),
      themeMode: ThemeMode.system,
      home: const MainScreen(),
    );
  }
}
```

*   **`StatelessWidget` (상태가 없는 위젯):**
    *   `MyApp`은 `StatelessWidget`을 상속받습니다. 이는 `MyApp` 위젯 자체는 내부에 변경 가능한 데이터를 가지지 않는다는 의미입니다.
    *   한 번 화면에 그려진 후에는 스스로의 모습을 바꾸지 않습니다. 앱의 제목이나 테마처럼 처음에 한 번 설정되고 거의 바뀌지 않는 속성들을 정의하기에 적합합니다.

*   **`build()` 메소드:**
    *   모든 위젯은 `build` 메소드를 가집니다. 이 메소드는 Flutter 프레임워크에 의해 호출되며, "이 위젯이 어떻게 생겨야 하는지"를 정의한 설계도를 반환합니다.
    *   Flutter는 이 설계도(위젯 트리)를 보고 실제 화면에 UI를 그립니다. `MyApp`의 `build` 메소드는 `MaterialApp` 위젯을 반환하여 앱의 기본 골격을 만듭니다.

*   **`MaterialApp` 위젯:**
    *   구글의 머티리얼 디자인 철학을 따르는 앱을 만드는 데 필요한 모든 기본 기능을 제공하는 매우 중요한 위젯입니다. 이 위젯으로 앱 전체를 감싸면 머티리얼 디자인 스타일의 UI 요소, 화면 전환(네비게이션), 테마 등을 손쉽게 사용할 수 있습니다.
    *   **`title`**: 앱의 전체적인 정체성을 나타내는 제목입니다. 운영체제의 앱 전환기 등에서 사용자에게 표시됩니다.
    *   **`theme`**: 앱의 기본 디자인 테마를 설정합니다. `ThemeData` 위젯을 사용하여 앱 전체의 색상(기본 색상, 배경색 등), 글꼴, 버튼 스타일 등을 한 번에 정의할 수 있습니다. 여기서 설정한 스타일은 하위의 모든 위젯에 기본값으로 적용됩니다.
    *   **`darkTheme`**: 사용자가 디바이스를 다크 모드로 설정했을 때 적용될 테마입니다. `theme` 속성과 마찬가지로 `ThemeData`를 사용하여 어두운 환경에 맞는 별도의 디자인을 정의할 수 있습니다.
    *   **`themeMode`**: 앱의 테마를 어떤 모드로 보여줄지 결정합니다.
        *   `ThemeMode.light`: 항상 `theme`에 설정된 라이트 모드로만 표시합니다.
        *   `ThemeMode.dark`: 항상 `darkTheme`에 설정된 다크 모드로만 표시합니다.
        *   `ThemeMode.system`: 사용자의 시스템(OS) 설정에 따라 라이트 모드와 다크 모드를 자동으로 전환합니다. 가장 일반적인 설정입니다.
    *   **`home`**: 앱이 실행되었을 때 사용자에게 가장 먼저 보여줄 화면(위젯)을 지정합니다. `home` 속성에 지정된 위젯이 앱의 첫 페이지가 됩니다. 이 예제에서는 `MainScreen` 위젯을 첫 화면으로 설정했습니다.

#### 4. `MainScreen` & `_MainScreenState`: 동적인 메인 화면

`StatefulWidget`은 사용자와의 상호작용이나 데이터 변경에 따라 화면이 바뀌는 동적인 위젯입니다. 실제 상태 관리와 UI 구성은 `State` 객체(`_MainScreenState`)가 담당합니다.

```dart
// lib/main.dart

class MainScreen extends StatefulWidget {
  // ...
}

class _MainScreenState extends State<MainScreen> {
  // 변수 선언, 메소드 선언, UI 구성 등이 여기에 위치합니다.

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(...),
      body: StepTabPage(...),
    );
  }
}
```

### 변수 선언: 데이터를 저장하는 공간

변수는 숫자, 글자 등 특정 데이터를 저장하는 공간입니다.

**기본 문법:** `자료형 변수이름 = 초기값;`

*   `int`: 정수
*   `double`: 실수
*   `String`: 문자열
*   `bool`: 참/거짓 (`true`/`false`)

**예시 (`main.dart`):**

```dart
// lib/main.dart/_MainScreenState

int _steps = 0; // 현재 걸음 수를 저장하는 정수형 변수
bool _isSimulationMode = false; // 시뮬레이션 모드 상태를 저장하는 불리언 변수
double _simulationSpeed = 5.0; // 시뮬레이션 속도를 저장하는 실수형 변수
```

### 메소드(함수) 선언: 특정 작업을 수행하는 코드 묶음

메소드는 특정 기능을 수행하는 코드들의 묶음으로, 재사용이 가능합니다.

**기본 문법:** `반환타입 메소드이름(매개변수) { // 실행할 코드 }`

*   **반환타입:** 메소드 작업 후 돌려주는 값의 타입. 없으면 `void`.
*   **매개변수(Parameter):** 메소드가 작업할 때 외부로부터 받을 데이터.

**예시 1: 매개변수가 없는 메소드**

```dart
// lib/main.dart/_MainScreenState

void _startSimulation() {
  if (_isSimulationMode && !_animationController.isAnimating) {
    _animationController.repeat(reverse: true);
  }
}
```

**예시 2: 매개변수가 있는 메소드**

이 메소드는 `bool` 타입의 데이터를 하나 받아야 하며, 받은 데이터를 `value`라는 이름으로 사용합니다.

```dart
// lib/main.dart/_MainScreenState

void _toggleSimulationMode(bool value) {
  setState(() {
    _isSimulationMode = value;
    // ...
  });
}
```

### 메소드 호출: 선언된 메소드 실행하기

선언된 메소드는 필요한 곳에서 "호출"하여 실행시킬 수 있습니다.

**기본 문법:** `메소드이름(전달할 값);`

**예시 1: 매개변수 없이 호출**

`initState` 메소드 안에서 `initPedometer` 메소드를 호출하여 실행합니다.

```dart
// lib/main.dart/_MainScreenState

@override
void initState() {
  super.initState();
  initPedometer(); // 메소드 호출!
}

void initPedometer() {
  // ... 걸음 수 측정 시작 코드
}
```

**예시 2: 매개변수를 전달하며 호출**

`_toggleSimulationMode` 메소드를 호출하면서, `true`라는 `bool` 값을 매개변수로 전달합니다.

```dart
// lib/main.dart/_MainScreenState

void _onStepCountError(error) {
  if (mounted && !_isSimulationMode) {
    // ...
    _toggleSimulationMode(true); // 'true' 값을 전달하며 메소드 호출!
  }
}
```
