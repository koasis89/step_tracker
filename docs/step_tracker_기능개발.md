# `step_tracker` 앱 기능 개발 요약

이 문서는 Flutter로 제작된 만보계 앱의 주요 기능과 개발 내역을 요약한 것입니다.

---

## 1. 개요 (Overview)

*   **애플리케이션**: Flutter 기반의 만보계 앱
*   **주요 추적 데이터**: 사용자의 걸음 수, 이동 거리, 소모 칼로리, 활동 시간
*   **핵심 모드**:
    *   **라이브 모드**: 실제 하드웨어 센서를 이용한 실시간 데이터 추적
    *   **시뮬레이션 모드**: 기능 테스트 및 데모를 위한 가상 데이터 생성
*   **특징**: 사용자의 움직임이 멈추면 자동으로 타이머가 일시 중지되는 '스마트 타이머' 기능

---

## 2. 주요 기능 상세 (Features)

### 라이브 모드 (Live Mode)
*   **실시간 걸음 수 추적**: `pedometer` 패키지를 사용하여 디바이스 센서에서 실시간 걸음 수를 가져옵니다.
*   **GPS 기반 활동 추적**: `geolocator` 패키지를 사용하여 사용자의 GPS 위치를 모니터링합니다.
*   **스마트 타이머**: 5초 동안 걸음이나 중요한 위치 변화가 감지되지 않으면 활동 타이머가 자동으로 일시 중지되어 정확한 활동 시간을 보장합니다.

### 시뮬레이션 모드 (Simulation Mode)
*   **가상 데이터 생성**: 물리적 센서 없이 걸음, 거리, 칼로리, 시간 데이터 생성을 시뮬레이션합니다.
*   **수동 제어**: '시작' 및 '중지' 버튼으로 시뮬레이션을 제어합니다.
*   **시간 및 가속도 제어**:
    *   **가상 시간 여행**: 특정 날짜와 시간으로 이동하여 과거 또는 미래의 데이터를 기록하고 테스트할 수 있습니다.
    *   **가속 배율**: 걸음 수, 거리, 칼로리, 시간의 증가 속도를 조절하여 장기간의 데이터 변화를 빠르게 테스트할 수 있습니다.

### 데이터 관리
*   **로컬 데이터베이스**: `Hive`를 사용하여 모든 운동 기록을 디바이스에 로컬로 저장합니다.
*   **데이터 분리 저장**: 10분 단위로 데이터를 기록하며, 계산의 기준이 되는 **'총 누적 데이터'**(`_total` 접미사 키)와 분석에 사용될 **'순수 활동량(델타)'**을 별도로 저장하여 데이터의 정확성과 활용도를 높였습니다.
*   **클라우드 동기화**: 로컬에 저장된 데이터를 `Firebase Firestore`와 동기화하는 기능을 제공합니다.
*   **데이터 뷰어 및 초기화**: 디버그 모드에서만 활성화되는 '로컬 데이터베이스 뷰어'를 통해 저장된 모든 데이터를 확인하고, 필요시 모든 데이터를 삭제하여 초기화할 수 있습니다.

### UI/UX
*   **걷기 애니메이션**: 사용자의 걷는 동작을 시각적으로 표현하는 커스텀 애니메이션을 제공합니다.
*   **테마 전환**: 라이트 모드와 다크 모드를 전환할 수 있는 기능을 제공합니다.
*   **직관적인 데이터 표시**: 걸음 수를 중심으로 거리, 시간, 칼로리 등 주요 지표를 명확하게 표시합니다.

## 3. 수정된 주요 소스 목록 (Modified Source Files)

*   `lib/screens/main_screen.dart`: 앱의 메인 화면. 모드 전환(라이브/시뮬레이션), 테마 변경, 데이터 동기화 및 Hive 뷰어 접근 로직을 포함합니다.
*   `lib/screens/live_screen.dart`: 실제 센서(만보계, GPS) 데이터를 받아와 화면에 표시하고, '스마트 타이머'를 관리하며, 데이터를 Hive에 저장하는 로직을 포함합니다.
*   `lib/screens/simulation_screen.dart`: 가상 걸음 데이터를 생성하고, 시간/가속도 조절 기능을 제공하며, 특정 시점의 데이터를 Hive에 저장하는 로직을 포함합니다.
*   `lib/screens/hive_viewer_screen.dart`: Hive 로컬 데이터베이스의 내용을 확인하고, 모든 데이터를 초기화하는 기능을 제공합니다.
*   `lib/models/fitness_record.dart`: 걸음 수, 거리, 칼로리 등 운동 데이터를 저장하기 위한 데이터 모델입니다. Hive 저장을 위해 `HiveObject`를 상속받습니다.
*   `pubspec.yaml`: `pedometer`, `geolocator`, `hive`, `provider` 등 기능 구현에 필요한 패키지들을 추가했습니다.
*   `android/app/src/main/AndroidManifest.xml`: 활동 인식 및 위치 정보 접근 권한을 추가했습니다.
*   `ios/Runner/Info.plist`: 활동 및 피트니스, 위치 정보 사용 목적에 대한 설명을 추가했습니다.
