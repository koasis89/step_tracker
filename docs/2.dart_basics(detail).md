## 가. Dart 소스 구성 및 주요 메소드

### `main.dart` : Flutter 앱의 시작점

`main.dart` 파일은 Flutter 앱의 가장 핵심적인 파일입니다. 앱이 시작될 때 가장 먼저 실행되는 코드가 바로 여기에 있습니다. 코드를 부분별로 나누어 쉽게 설명해 드릴게요.

#### 1. `import` 문: 필요한 도구 가져오기

```dart
import 'dart:async';
import 'package:flutter/material.dart';
import 'package:pedometer/pedometer.dart';
import 'package:myapp/tabs/step_tab_page.dart';
```

* `import`는 다른 파일에 있는 코드(클래스, 함수 등)를 현재 파일에서 사용하고 싶을 때 사용합니다.
* `dart:async`: 비동기 프로그래밍(예: 시간차를 두고 실행되는 작업)에 필요한 도구들을 가져옵니다.
* `package:flutter/material.dart`: 구글의 머티리얼 디자인 가이드라인을 따르는 예쁜 UI 요소(위젯)들을 가져옵니다. (예: `Scaffold`, `AppBar`, `Text` 등)
* `package:pedometer/pedometer.dart`: 걸음 수를 감지하는 기능을 가진 외부 라이브러리(패키지)를 가져옵니다.
* `package:myapp/tabs/step_tab_page.dart`: 우리가 만든 다른 화면 파일(`step_tab_page.dart`)을 가져옵니다.

#### 2. `main()` 함수: 앱의 시작

```dart
void main() {
  runApp(const MyApp());
}
```

* 모든 Dart 프로그램은 `main()` 함수에서 시작됩니다.
* `runApp()` 함수는 Flutter 앱을 실행하는 역할을 합니다.
* `MyApp()`이라는 위젯을 `runApp()`에 전달하여 화면에 표시할 첫 번째 위젯을 알려줍니다.

#### 3. `MyApp` 클래스: 앱의 기본 틀 만들기

```dart
class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Pedometer App',
      theme: ThemeData(...),
      darkTheme: ThemeData(...),
      themeMode: ThemeMode.system,
      home: const MainScreen(),
    );
  }
}
```

* `StatelessWidget`: 상태가 없는 정적인 위젯입니다. 즉, 화면에 한 번 그려지면 내용이 바뀌지 않습니다.
* `build()`: 위젯이 화면에 어떻게 보일지 정의하는 함수입니다.
* `MaterialApp`: 머티리얼 디자인 앱을 만드는 데 필요한 기본적인 틀을 제공합니다.
    * `title`: 앱의 제목입니다.
    * `theme`: 앱의 전체적인 디자인 테마(색상, 글꼴 등)를 설정합니다. 밝은 모드 테마입니다.
    * `darkTheme`: 다크 모드일 때의 테마를 설정합니다.
    * `themeMode`: 시스템 설정에 따라 테마를 자동으로 변경합니다.
    * `home`: 앱이 처음 시작될 때 보여줄 화면을 지정합니다. 여기서는 `MainScreen` 위젯을 보여줍니다.

#### 4. `MainScreen` 클래스: 실제 콘텐츠가 표시되는 화면

```dart
class MainScreen extends StatefulWidget {
  const MainScreen({super.key});

  @override
  State<MainScreen> createState() => _MainScreenState();
}
```

* `StatefulWidget`: 상태가 있는 동적인 위젯입니다. 즉, 사용자와 상호작용하거나 데이터가 변경됨에 따라 화면이 바뀔 수 있습니다.
* `createState()`: `StatefulWidget`의 상태를 관리하는 `State` 객체를 생성합니다. `_MainScreenState`가 그 역할을 합니다.

#### 5. `_MainScreenState` 클래스: 화면의 상태 관리 및 UI 구성

```dart
class _MainScreenState extends State<MainScreen> with TickerProviderStateMixin {
  int _steps = 0;
  // ... 다른 변수들 ...

  @override
  void initState() {
    super.initState();
    // ... 초기화 코드 ...
  }

  @override
  void dispose() {
    // ... 리소스 해제 코드 ...
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(...),
      body: StepTabPage(...),
    );
  }
}
```

* **`_steps`**: 걸음 수를 저장하는 변수입니다. 변수 이름 앞의 `_`는 "이 변수는 이 파일 안에서만 사용할 거야"라는 의미입니다.
* **`initState()`**: 위젯이 처음 생성될 때 딱 한 번 호출됩니다. 여기서 변수를 초기화하거나 이벤트 리스너를 등록합니다.
* **`dispose()`**: 위젯이 화면에서 사라질 때 호출됩니다. 여기서 사용했던 리소스를 정리합니다.
* **`build()`**: 화면을 그리는 가장 중요한 부분입니다.
    * `Scaffold`: 앱 화면의 기본적인 구조(상단 바, 본문 등)를 제공합니다.
    * `appBar`: 화면 상단의 제목 표시줄입니다.
    * `body`: 화면의 본문 내용입니다. `StepTabPage`라는 다른 위젯을 보여주고 있습니다.
* **`setState()`**: 이 함수를 호출하면 Flutter에게 "상태가 바뀌었으니 화면을 다시 그려줘!"라고 알려줍니다. 예를 들어 걸음 수가 증가하면 `setState()`를 호출하여 화면의 숫자도 업데이트합니다.

### 핵심 문법 및 개념 요약

* **위젯 (Widget)**: Flutter에서 UI를 구성하는 모든 것입니다. (예: `Text`, `Image`, `Button`, `Container` 등)
* **`StatelessWidget` vs. `StatefulWidget`**:
    * `StatelessWidget`: 정적인 화면. 한 번 그려지면 바뀌지 않음.
    * `StatefulWidget`: 동적인 화면. 데이터 변경에 따라 화면이 다시 그려짐.
* **`build()` 메소드**: 위젯이 화면에 어떻게 보일지를 정의하는 설계도와 같습니다.
* **`setState()`**: `StatefulWidget`에서 화면을 다시 그리도록 요청하는 함수입니다.
* **`MaterialApp`과 `Scaffold`**: 머티리얼 디자인 앱의 기본 뼈대를 이루는 중요한 위젯입니다.

### `MyApp` 클래스 상세 설명: 앱의 최상위 루트 위젯

`MyApp` 클래스는 앱 전체의 시작점이자 최상위(루트) 위젯입니다. 앱의 기본 설정과 구조를 정의합니다.

*   **`StatelessWidget` (상태가 없는 위젯):**
    *   `MyApp`은 `StatelessWidget`을 상속받습니다. 이는 `MyApp` 위젯 자체는 내부에 변경 가능한 데이터를 가지지 않는다는 의미입니다.
    *   한 번 화면에 그려진 후에는 스스로의 모습을 바꾸지 않습니다. 앱의 제목이나 테마처럼 처음에 한 번 설정되고 거의 바뀌지 않는 속성들을 정의하기에 적합합니다.

*   **`build()` 메소드:**
    *   모든 위젯은 `build` 메소드를 가집니다. 이 메소드는 Flutter 프레임워크에 의해 호출되며, "이 위젯이 어떻게 생겨야 하는지"를 정의한 설계도를 반환합니다.
    *   Flutter는 이 설계도(위젯 트리)를 보고 실제 화면에 UI를 그립니다. `MyApp`의 `build` 메소드는 `MaterialApp` 위젯을 반환하여 앱의 기본 골격을 만듭니다.

*   **`MaterialApp` 위젯:**
    *   구글의 머티리얼 디자인 철학을 따르는 앱을 만드는 데 필요한 모든 기본 기능을 제공하는 매우 중요한 위젯입니다. 이 위젯으로 앱 전체를 감싸면 머티리얼 디자인 스타일의 UI 요소, 화면 전환(네비게이션), 테마 등을 손쉽게 사용할 수 있습니다.
    *   **`title`**: 앱의 전체적인 정체성을 나타내는 제목입니다. 운영체제의 앱 전환기 등에서 사용자에게 표시됩니다.
    *   **`theme`**: 앱의 기본 디자인 테마를 설정합니다. `ThemeData` 위젯을 사용하여 앱 전체의 색상(기본 색상, 배경색 등), 글꼴, 버튼 스타일 등을 한 번에 정의할 수 있습니다. 여기서 설정한 스타일은 하위의 모든 위젯에 기본값으로 적용됩니다.
    *   **`darkTheme`**: 사용자가 디바이스를 다크 모드로 설정했을 때 적용될 테마입니다. `theme` 속성과 마찬가지로 `ThemeData`를 사용하여 어두운 환경에 맞는 별도의 디자인을 정의할 수 있습니다.
    *   **`themeMode`**: 앱의 테마를 어떤 모드로 보여줄지 결정합니다.
        *   `ThemeMode.light`: 항상 `theme`에 설정된 라이트 모드로만 표시합니다.
        *   `ThemeMode.dark`: 항상 `darkTheme`에 설정된 다크 모드로만 표시합니다.
        *   `ThemeMode.system`: 사용자의 시스템(OS) 설정에 따라 라이트 모드와 다크 모드를 자동으로 전환합니다. 가장 일반적인 설정입니다.
    *   **`home`**: 앱이 실행되었을 때 사용자에게 가장 먼저 보여줄 화면(위젯)을 지정합니다. `home` 속성에 지정된 위젯이 앱의 첫 페이지가 됩니다. 이 예제에서는 `MainScreen` 위젯을 첫 화면으로 설정했습니다.

## 나. Dart 기본 문법(변수,메소드)

### 1. 변수 선언: 데이터를 저장하는 상자

변수는 숫자, 글자, 참/거짓 등 특정 데이터를 저장하는 공간(상자)이라고 생각하면 쉽습니다.

**기본 문법:**

```dart
자료형 변수이름 = 초기값;
```

*   **자료형:** 이 상자에 어떤 종류의 데이터를 담을지 알려줍니다.
    *   `int`: 정수 (예: 1, 100, -5)
    *   `double`: 실수 (예: 3.14, -0.5)
    *   `String`: 문자열 (예: "안녕하세요")
    *   `bool`: 참/거짓 (예: `true`, `false`)
*   **변수이름:** 이 상자를 부를 때 사용할 이름입니다.
*   **초기값:** 상자에 처음으로 넣어둘 데이터입니다.

**`main.dart` 파일의 예시:**

`_MainScreenState` 클래스 안에 있는 아래 코드를 보세요.

```dart
// lib/main.dart

class _MainScreenState extends State<MainScreen> with TickerProviderStateMixin {
  int _steps = 0; // ① 정수형 변수 선언
  bool _isSimulationMode = false; // ② 불리언(참/거짓) 변수 선언
  double _simulationSpeed = 5.0; // ③ 실수형 변수 선언

  // ... (이하 생략)
}
```

1.  **`int _steps = 0;`**
    *   `int` 자료형의 `_steps`라는 이름의 변수를 선언하고, 초기값으로 `0`을 저장했습니다.
    *   이 변수는 현재 걸음 수를 저장하는 역할을 합니다.
    *   변수 이름 앞의 밑줄(`_`)은 "이 변수는 이 클래스 안에서만 사용할 거예요"라는 뜻의 관례입니다.

2.  **`bool _isSimulationMode = false;`**
    *   `bool` 자료형의 `_isSimulationMode`라는 변수를 선언하고, 초기값으로 `false`를 저장했습니다.
    *   시뮬레이션 모드가 켜져 있는지(`true`) 꺼져 있는지(`false`) 상태를 저장합니다.

3.  **`double _simulationSpeed = 5.0;`**
    *   `double` 자료형의 `_simulationSpeed`라는 변수를 선언하고, 초기값으로 `5.0`을 저장했습니다.
    *   시뮬레이션의 속도를 저장하는 변수입니다.

### 2. 메소드(함수) 선언: 특정 작업을 수행하는 코드 묶음

메소드(또는 함수)는 특정 기능을 수행하는 코드들의 묶음입니다. 코드를 재사용하고, 역할을 명확하게 나눌 수 있어 매우 유용합니다.

**기본 문법:**

```dart
반환타입 메소드이름(매개변수) {
  // 실행하고 싶은 코드 내용
  // ...
}
```

*   **반환타입:** 메소드가 작업을 마친 후 돌려주는 값의 자료형입니다. 돌려주는 값이 없으면 `void`라고 씁니다.
*   **메소드이름:** 이 코드 묶음을 부를 때 사용할 이름입니다.
*   **매개변수 (Parameter):** 메소드가 작업을 수행할 때 외부로부터 받을 데이터입니다. 필요 없으면 `()` 안을 비워둡니다.

**`main.dart` 파일의 예시:**

##### 예시 1: 매개변수가 없는 간단한 메소드

```dart
// lib/main.dart

  void _startSimulation() {
    if (_isSimulationMode && !_animationController.isAnimating) {
      _animationController.repeat(reverse: true);
    }
  }
```

*   `void`: 이 메소드는 작업을 마친 후 아무것도 돌려주지 않는다는 의미입니다.
*   `_startSimulation`: 메소드의 이름입니다.
*   `()`: 외부에서 받는 데이터(매개변수)가 없다는 의미입니다.
*   `{...}`: 시뮬레이션 애니메이션을 시작하는 코드가 들어있습니다.

##### 예시 2: 매개변수가 있는 메소드

```dart
// lib/main.dart

  void _toggleSimulationMode(bool value) {
    setState(() {
      _isSimulationMode = value;
      // ... (이하 생략)
    });
  }
```

*   `void`: 이 메소드도 돌려주는 값은 없습니다.
*   `_toggleSimulationMode`: 메소드의 이름입니다.
*   `(bool value)`: 이 메소드는 호출될 때 `bool` 타입의 데이터 하나를 꼭 받아야 하며, 받은 데이터를 메소드 안에서 `value`라는 이름으로 사용하겠다는 의미입니다.

### 3. 메소드 호출: 선언된 메소드를 실행시키기

메소드를 선언했다면, 이제 필요한 곳에서 그 메소드를 "호출"해서 실행시킬 수 있습니다.

**기본 문법:**

```dart
메소드이름(전달할 값);
```

*   호출하고 싶은 메소드의 이름을 적고, 만약 그 메소드가 매개변수를 받는다면 `()` 안에 해당 자료형의 값을 넣어줍니다.

**`main.dart` 파일의 예시:**

##### 예시 1: 매개변수 없이 호출하기

```dart
// lib/main.dart

  @override
  void initState() {
    super.initState();
    // ...
    initPedometer(); // initPedometer 메소드를 호출!
  }

  void initPedometer() { // <- 호출될 메소드
    if (_isSimulationMode) return;
    _stepCountSubscription = Pedometer.stepCountStream.listen(
      _onStepCount,
      onError: _onStepCountError
    );
  }
```

*   `initState` 메소드 안에서 `initPedometer();` 코드를 통해 `initPedometer` 메소드를 실행시키고 있습니다.

##### 예시 2: 매개변수를 전달하며 호출하기

```dart
// lib/main.dart

  void _onStepCountError(error) {
    print('Pedometer Error: $error');
    if (mounted && !_isSimulationMode) {
      setState(() {
        print("Sensor not found, switching to simulation mode");
        _toggleSimulationMode(true); // _toggleSimulationMode 메소드를 'true'라는 값을 전달하며 호출!
      });
    }
  }
```

*   `_onStepCountError` 메소드 안에서 `_toggleSimulationMode(true);` 코드가 있습니다.
*   이는 `_toggleSimulationMode` 메소드를 호출하면서, `true`라는 `bool` 값을 매개변수로 전달하는 것입니다.
*   따라서 `_toggleSimulationMode` 메소드 안의 `value`라는 변수에는 `true`가 담기게 되고, `_isSimulationMode = true;`가 실행됩니다.
