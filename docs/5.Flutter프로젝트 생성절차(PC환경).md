## PC환경에서 Flutter 프로젝트 생성 절차
**Firebase 콘솔 설정 → Flutter 프로젝트 생성/연동 → 플랫폼별(안드/ iOS) 마무리**까지, 팀 온보딩용으로 **단계별 체크리스트** 형태로 정리

### 1) Firebase 콘솔 프로젝트 생성

1. **프로젝트 생성**

   * Firebase Console 접속 → **Add project**.
   * 프로젝트 이름 입력(예: `spoker-prod`), **Google Analytics**는 필요 시 활성화.
   * 생성 완료까지 대기.

2. **필수 제품 활성화**

   * **Authentication** → Sign-in method → **Email/Password**(필수), **Google**(선택) **Enable**.
   * **Firestore Database** → **Create database** → 시작 모드 선택(개발 초기엔 테스트 규칙 OK, 출시 전 보안규칙 강화 필수).
   * **Cloud Functions**: 별도 화면 설정은 불필요. 나중에 CLI로 배포.
   * **Cloud Messaging(FCM)**: 콘솔 자동 활성화. iOS 푸시용 **APNs 키**는 나중 단계에서 업로드.

3. **프로젝트 설정 값 확보**

   * **Project settings** → **General** 탭에서 **Project ID**, **Web API key** 확인.
   * **Service accounts** 탭의 Admin SDK는 Functions(서버) 쪽에서 자동 사용됨(로컬 에뮬레이터 제외).

### 2) Flutter 프로젝트 생성 
(Android Studio 또는 VS Code)

1. **Flutter SDK/도구 설치 확인**

   * 터미널: `flutter doctor` → 이슈 있으면 해결(안드로이드 SDK, Xcode 등).

2. **신규 프로젝트 생성**

   * Android Studio: New Flutter Project → Application → 프로젝트명 `spoker_app`.
   * VS Code: `Flutter: New Project` → 같은 이름.
   * 경로 예: `~/dev/spoker_app`.

3. **필수 패키지 추가 (pubspec.yaml)**

   ```yaml
   dependencies:
     flutter:
       sdk: flutter
     firebase_core: ^latest
     cloud_firestore: ^latest
     firebase_auth: ^latest
     firebase_messaging: ^latest
     firebase_functions: ^latest
     firebase_storage: ^latest
   ```

   * 저장 후: `flutter pub get`.

### 3) FlutterFire CLI로 Firebase 연결(권장)

> 최신 권장 플로우. 콘솔에서 수동 다운로드도 가능하지만, **FlutterFire CLI**가 플랫폼 설정을 자동화한다.

1. **CLI 설치**

   ```bash
   dart pub global activate flutterfire_cli
   ```

   PATH에 `~/.pub-cache/bin` 추가 확인.

2. **로그인 및 프로젝트 연결**

   ```bash
   flutterfire configure
   ```

   * Google 계정 로그인 → 사용할 Firebase 프로젝트 선택(`spoker-prod`).
   * **Android** 앱 패키지명 입력(예: `com.spo.company.spoker`), **iOS** 번들 ID 입력(예: `com.spo.company.spoker`).
   * 안드로이드 **SHA-1/ SHA-256** 요구 시: Android Studio의 **Gradle signing report**로 추출 후 콘솔에 등록(선택이지만 Google 로그인/동적 링크 쓸 때 필요).
   * 완료 시, 루트에 `firebase_options.dart` 생성됨 + 각 플랫폼 설정 자동 반영.

3. **앱 부팅 코드 초기화**

   ```dart
   // lib/main.dart
   import 'package:flutter/material.dart';
   import 'package:firebase_core/firebase_core.dart';
   import 'firebase_options.dart';

   void main() async {
     WidgetsFlutterBinding.ensureInitialized();
     await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
     runApp(const MyApp());
   }

   class MyApp extends StatelessWidget {
     const MyApp({super.key});
     @override
     Widget build(BuildContext context) {
       return MaterialApp(
         title: 'SpoKer',
         home: const Scaffold(body: Center(child: Text('Firebase OK'))),
       );
     }
   }
   ```

### 4) Android 설정 (AGP 8.x 기준)

FlutterFire가 대부분 처리하지만, 점검 포인트 정리.

1. **Gradle 플러그인/리포지토리 점검**

   * `android/settings.gradle`의 `pluginManagement`와 `repositories`에 `google()` 포함 확인.
   * `android/build.gradle` 또는 `settings.gradle`에 **com.google.gms:google-services** 플러그인 버전 최신 확인.

2. **앱 레벨 Gradle**

   * `android/app/build.gradle` 하단에 **Google Services 플러그인 적용**:

     ```gradle
     plugins {
       id "com.android.application"
       id "kotlin-android"
       id "com.google.gms.google-services"
     }
     ```
   * minSdkVersion(예: 21 이상) 확인.
   * `google-services.json` 존재 확인(FlutterFire가 자동 생성/배치. 수동일 경우 `android/app/`에 둔다).

3. **FCM 권한/채널(선택)**

   * Android 13+ 알림 권한 런타임 요청 필요. 앱 최초 실행 시 알림 권한 다이얼로그 처리 로직 준비.

# 5) iOS 설정 (Xcode, Cocoapods)

1. **기본 설정**

   * `ios/Runner/`에 `GoogleService-Info.plist` 존재 확인(FlutterFire가 자동). 수동일 경우 Xcode에서 **Runner** 타겟에 **Add Files**로 추가.
   * `cd ios && pod install` (필요 시 `pod repo update` 후 재실행).

2. **권한/Capabilities**

   * **Push Notifications**, **Background Modes**(Remote notifications) 활성화.
   * 앱 ID/프로비저닝이 푸시 가능 계정으로 구성되어야 FCM 동작.
   * FCM용 **APNs 인증키(.p8)** 를 Firebase 콘솔 **Project settings → Cloud Messaging**에 업로드(Team ID/Key ID 입력).

3. **알림 권한 요청(Dart)**

   ```dart
   final messaging = FirebaseMessaging.instance;
   await messaging.requestPermission(alert: true, badge: true, sound: true);
   ```

### 6) Cloud Functions(TypeScript) 초기화(선택·서버 로직 필요 시)

> 보상 룰렛/Seed 전환/리더보드 집계 등 서버 로직이 필요할 때.

1. **Functions 초기화**

   ```bash
   firebase login
   firebase init functions
   # TypeScript 선택, ESLint 선택, npm install 진행
   ```

2. **샘플 함수 추가**

   ```ts
   // functions/src/index.ts
   import * as functions from "firebase-functions";
   import * as admin from "firebase-admin";
   admin.initializeApp();

   export const ping = functions.https.onCall(async () => {
     return { ok: true, ts: Date.now() };
   });
   ```

3. **배포**

   ```bash
   firebase deploy --only functions
   ```

4. **Flutter에서 호출**

   ```dart
   final res = await FirebaseFunctions.instance.httpsCallable('ping')();
   print(res.data); // { ok: true, ts: ... }
   ```

### 7) Firestore 보안규칙(개발→운영 전환 체크)

* 개발 초기(테스트 규칙):

  ```rules
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /{document=**} {
        allow read, write: if request.time < timestamp.date(2099,1,1);
      }
    }
  }
  ```
* 출시 전(예시—인증 사용자만 접근):

  ```rules
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      function isSignedIn() { return request.auth != null; }

      match /users/{uid}/{document=**} {
        allow read, write: if isSignedIn() && request.auth.uid == uid;
      }

      match /public/{doc=**} {
        allow read: if true;
        allow write: if false;
      }
    }
  }
  ```

### 8) FCM 수신 기본 처리

```dart
void initMessaging() {
  FirebaseMessaging.onMessage.listen((RemoteMessage message) {
    // 포그라운드 수신 처리
    debugPrint('Push received: ${message.notification?.title}');
  });

  FirebaseMessaging.onBackgroundMessage(_bgHandler);
}

@pragma('vm:entry-point')
Future<void> _bgHandler(RemoteMessage message) async {
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
  // 백그라운드 로직
}
```

### 9) 실행 검증

1. **초기화 확인**

   * `flutter run` (안드로이드 에뮬레이터 또는 iOS 시뮬레이터)
   * 콘솔 로그에 `FirebaseApp initialized` 유사 메시지 확인.

2. **Firestore Write/Read 스모크 테스트**

   ```dart
   print(qs.docs.first.data());
   ```

3. **Functions 호출 테스트**(위 ping 예제)

4. **FCM 토큰/권한 확인**

   ```dart
   final token = await FirebaseMessaging.instance.getToken();

   ```

### 10) 트러블슈팅 포인트

* **Android 빌드 오류(google-services)**

  * `com.google.gms:google-services` 플러그인 적용 누락 여부 확인.
  * `google-services.json` 경로 `android/app/` 확인.

* **iOS Pod 에러**

  * `cd ios && pod deintegrate && pod install` 재시도.
  * Xcode에서 **Signing & Capabilities** 팀/프로파일 점검.

* **Functions 배포 실패**

  * `firebase use <projectId>`로 대상 프로젝트 확인.
  * Node 버전/권한 오류 시 `nvm`으로 LTS(예: 18) 사용.

* **FCM 푸시 미수신(iOS)**

  * APNs 키 업로드 여부, Capabilities 설정, 실제 디바이스 테스트(시뮬레이터는 푸시 제한).
